# Out of Control

*A chaotic indie arcade platformer where your controls change each level*

[click here to play the interactive web version on itch.io!](https://antiendless.itch.io/out-of-control)

## 🚀 Quick Start
1. Clone or download this repository asset folder.
2. Launch the game executable layout.
3. Use the dynamic movement controls to navigate the platforms.
4. Press **ESC** at any time to freeze time, open the options panel, or exit to the main title screen.
5. Dash through the door trigger zones across Levels 1 to 5 to reset the cycle and attempt a perfect loop!

## 🕹️ About the Game
**Out of Control** is a fast-paced skill test where your environment stays steady but your physical inputs are constantly shifting. 

I built this project to challenge muscle memory. Every time you cross custom level trigger frames, step through doors, or complete tasks, your input matrix scrambles into completely new combinations. You have to adapt on the fly to survive!

### Key Features
* **Scrambled Inputs Matrix:** Directional and interaction button keys scramble dynamically across custom movement configurations.
* **Cinematic Transitions Engine:** Implements high-performance canvas group fade overlays between level loads smoothly.
* **Typographical Framing:** Designed completely with the blocky, retro pixel aesthetic of the **Mojangles** font asset.
