# Out of Control!

*A chaotic indie arcade platformer where your controls change each level*

[click here to play the web version on itch.io!](https://antiendless.itch.io/out-of-control)

## about the game!
**Out of Control!** is a 2D-arcade platformer rage game where your controls randomly change every level!

### key features:
* **Scrambled Inputs:** after the first level, your movement keys scramble randomly, you cam hold 'Tab' to check the new controls!
* **Moving platforms and spikes:** the levels have various types of moving platforms and spikes to add to the game (if  you weren't already raging enough :P
* **NO AI:** the core gameplay with the scripts, assest, etc use no ai whatsoever, the designs were completely either made by me, or I used assets that were there for free on itch.io. (**However**, I did use AI for the **initial** readme because I was getting late and needed to ship my project in time)
  
## made all of this using:
* **IDE:** VS code
* **Engine:** Unity 6
* **Fonts i used** Mojangles (for title. The rest were the default ones in Unity)
* **Tilemaps** SDF Atlas Map Asset
